Sinkronisasi Antar Device

Simpan data di Supabase agar semua perangkat menampilkan angka yang sama

Status: hanya lokal (data tersimpan di browser ini)
  1. Buat akun gratis di supabase.com → New project.
  2. Buka SQL Editor → tempel & jalankan skrip di bawah (membuat tabel penyimpanan).
  3. Di dashboard project, buka Settings (ikon gerigi, sidebar kiri bawah) → API Keys. Salin Project URL (bentuknya https://xxxx.supabase.co) dan Publishable key / anon key. Bisa juga lewat tombol Connect di atas dashboard.
  4. Isi Kode Ruang yang sama di setiap device. Kode ini yang menentukan data siapa yang dibuka — rahasiakan.
create table if not exists neraca_state (
  space_id   text primary key,
  data       jsonb not null,
  updated_at timestamptz not null default now(),
  device     text
);

alter table neraca_state enable row level security;

-- akses hanya bagi yang tahu kode ruang (bertindak sebagai kata sandi)
create policy "akses via kode ruang" on neraca_state
  for all to anon using (true) with check (true);
Keduanya diterima. Kunci ini memang dirancang untuk dipakai di sisi browser — jangan pakai service_role / secret key.
Siapa pun yang tahu kode ini bisa membuka data Anda — pakai yang sulit ditebak.
